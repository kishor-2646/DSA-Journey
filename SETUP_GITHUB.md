# 🚀 Setting Up This Repo on GitHub

A quick guide to get this live on GitHub and shareable on LinkedIn.

---

## Step 1 — Initialise Git

```bash
cd DSA-Journey
git init
git add .
git commit -m "🚀 Initial commit — DSA Journey started (Basics + Sorting + Arrays + Binary Search)"
```

---

## Step 2 — Create GitHub Repo

1. Go to [github.com/new](https://github.com/new)
2. Name it something like `DSA-Journey` or `Strivers-A2Z-Solutions`
3. Keep it **Public** (for sharing on LinkedIn)
4. Do **not** initialise with README (we already have one)

---

## Step 3 — Push to GitHub

```bash
git remote add origin https://github.com/YOUR_USERNAME/DSA-Journey.git
git branch -M main
git push -u origin main
```

---

## Step 4 — Pin the Repo

- Go to your GitHub profile
- Click **"Customize your pins"**
- Add `DSA-Journey` to your pinned repos

## 🔄 Updating Progress

After solving new problems:

```bash
git add .
git commit -m "✅ Add [Topic] — [Problem Name]"
git push
```

Suggested commit message conventions:
- `✅ Add BS — Koko Eating Bananas`
- `📝 Add notes — Kadane's Algorithm`
- `🖊 Add handwritten notes — Merge Sort`
- `🔧 Fix typo in Two Sum solution`
