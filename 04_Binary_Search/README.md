## 🧠 Key Patterns Learnt

| Pattern | When to Use | Problems |
|---------|------------|---------|
| **Classic BS** | Sorted array, find target | BS01–BS07 |
| **BS on Rotated** | Identify sorted half first | BS08–BS11 |
| **BS on Answer Space** | Minimise max / Maximise min | BSA03–BSA14 |
| **2D Matrix BS** | Treat matrix as 1D or staircase approach | BS2D01–05 |

### 💡 The BS on Answer Space Template

```
lo = min possible answer
hi = max possible answer
while lo <= hi:
    mid = (lo + hi) / 2
    if feasible(mid):
        ans = mid
        hi = mid - 1  // or lo = mid + 1 depending on minimise/maximise
    else:
        lo = mid + 1  // or hi = mid - 1
```
