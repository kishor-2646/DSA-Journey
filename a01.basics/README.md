- Pattern problems sharpen **loop control and index logic**
- Maths: Euclidean GCD, Sieve of Eratosthenes, digit extraction tricks
- Recursion: **functional** vs **parameterised** recursion, stack frame visualisation
- Hashing: frequency maps using `unordered_map`, array hashing for small ranges
