# 📸 Assets — Handwritten Notes

This folder stores photos of your handwritten notes for each problem.

---

## 📁 Naming Convention

```
{topic}_{problem-slug}_notes.jpg
```

### Examples:
| Topic | Problem | Filename |
|-------|---------|----------|
| Arrays | Two Sum | `arrays_two-sum_notes.jpg` |
| Binary Search | Aggressive Cows | `bs_aggressive-cows_notes.jpg` |
| Sorting | Merge Sort | `sorting_merge-sort_notes.jpg` |
| Basics | GCD | `basics_gcd_notes.jpg` |

---

## 🔗 How to Link in Problem Files

In your problem `.md` file, add this in the Handwritten Notes section:

```markdown
## 🖊 Handwritten Notes

![My Notes](../../assets/arrays_two-sum_notes.jpg)
```

Adjust the relative path based on the file's depth in the folder structure.

---

## 📷 Tips for Good Note Photos

1. Use good lighting — no shadows on the page
2. Keep the page flat; use a clip if needed
3. Crop tightly around your notes
4. Recommended: use a scanner app (Adobe Scan, CamScanner) for clean output
5. Compress if needed — keep images under 500KB for GitHub
